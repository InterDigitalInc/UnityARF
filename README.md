# UnityARF

![Unity 6000+ and URP recommended](https://img.shields.io/badge/Unity-6000.0%2B-brightgreen)

Unity package for importing Avatar Representation Format (.arf) assets.

Specification: MPEG-I Part 39, Avatar Representation Format, https://www.mpeg.org/standards/MPEG-I/39/

This version respects the standard defined during MPEG meeting 151.

# Installation

1. Open `Window > Package Manager`
2. Click <kbd>+</kbd>
3. Select <kbd>Add Package from git URL</kbd>
4. Paste
   ```
   https://github.com/InterDigitalInc/UnityARF.git
   ```
5. Click <kbd>Add</kbd>.
